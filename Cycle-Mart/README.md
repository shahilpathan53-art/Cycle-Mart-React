# 🚲 Cycle Mart React

This project is an Online Cycle Mart web application designed to purchase bicycles.

## 🧾 Project Description
The system allows users to browse cycles, place orders, and manage purchases online.  
It is a full-stack web application built with modern technologies.

## 🚀 Tech Stack
- Frontend: React (Vite), HTML, CSS, Bootstrap
- Backend: Node.js, Express.js
- Database: MongoDB

## 📂 Features
- User Registration & Login
- Browse Cycles / Products
- Add to Cart & Order System
- Admin Panel (Manage Products & Orders)
- Responsive UI

## ⚙️ Installation

```bash
npm install
npm run dev
